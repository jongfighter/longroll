# Longroll

세로로 긴 이미지(웹툰) 회차 폴더를 끊김 없이 이어서 읽는 Windows용 이미지 뷰어입니다.

## 주요 기능

- 한 회차 폴더의 이미지를 세로로 이어 붙여 스크롤하며 봅니다.
- 같은 만화 폴더 안의 이전/다음 회차로 바로 이동합니다(회차 폴더·이미지 파일 이름은 숫자 순으로 자연 정렬).
- 기본은 창 폭에 맞춰 표시합니다. 확대/축소(10%~800%), 창 폭 맞춤, 원본 크기(100%) 전환을 지원합니다.
- 상단 바에 만화명, 회차명, 회차 번호, 현재 장/전체 장, 이미지 크기, 배율을 표시합니다.
- 폴더나 이미지를 창에 끌어다 놓거나, 열기 대화상자, 이미지 파일의 "연결 프로그램"으로 열 수 있습니다. 이미 실행 중이면 같은 창에서 열립니다.
- 지원 형식: JPG, PNG, WebP, GIF, BMP, AVIF. 이미지는 읽기만 하며 수정하지 않습니다.

## 단축키와 마우스

| 입력 | 동작 |
|---|---|
| `←` / `→` | 이전 / 다음 회차 |
| `↑` / `↓` | 80px 위 / 아래로 스크롤 |
| `Space` / `Shift+Space` | 한 화면(90%) 아래 / 위로 부드럽게 스크롤 |
| `PageDown` / `PageUp` | 한 화면(90%) 아래 / 위로 부드럽게 스크롤 |
| `Home` / `End` | 현재 회차의 맨 위 / 맨 아래로 이동 |
| `Ctrl+O` / `Ctrl+Shift+O` | 파일 열기 / 폴더 열기 |
| `Ctrl` + `+` (`=` 키 또는 숫자패드 `+`) / `Ctrl` + `-` | 확대 / 축소 (1.25배씩) |
| `Ctrl+0` | 창 폭에 맞춤 |
| `Ctrl+1` | 원본 크기(100%) |
| `F11` / `Esc` | 전체 화면 전환 / 전체 화면 해제 |
| 마우스 휠 | 스크롤 |
| `Ctrl` + 마우스 휠 | 커서 위치를 기준으로 확대 / 축소 |
| 왼쪽 버튼 드래그 | 화면 이동 |
| 더블클릭 | 창 폭 맞춤 ↔ 100% 전환 |
| 마우스 뒤로 / 앞으로 버튼 | 이전 / 다음 회차 |
| 화면 가장자리 스크롤바 | 썸을 끌거나 트랙을 클릭해 이동 |

## 폴더 구조 규칙

`만화 폴더 > 회차 폴더 > 이미지` 구조를 기준으로 합니다.

```text
만화 폴더/
├─ 001화/
│  ├─ 01.jpg
│  └─ 02.jpg
└─ 002화/
   ├─ 01.jpg
   └─ 02.jpg
```

- 폴더를 열었을 때 그 안에 이미지가 직접 들어 있는 하위 폴더가 있으면, 그 폴더가 만화 폴더이고 하위 폴더들이 회차입니다. 이름 순으로 첫 번째 회차부터 열립니다.
- 하위 폴더에 이미지가 없고 폴더 자체에 이미지가 있으면 그 폴더가 한 회차이고, 부모 폴더가 만화 폴더입니다.
- 이미지 파일을 열면 그 파일이 든 폴더가 회차이고, 같은 부모 아래의 다른 이미지 폴더들이 다른 회차입니다.

## 다운로드

[Releases 의 최신 버전](https://github.com/jongfighter/longroll/releases/latest)에서 `Longroll-Setup-<버전>.exe` 를 받아 실행하세요. 설치 중 설치 위치를 바꿀 수 있습니다.

코드 서명이 없어서 처음 실행하면 Windows SmartScreen 이 "Windows의 PC 보호" 화면을 표시할 수 있습니다. 이때 **추가 정보** → **실행**을 누르면 됩니다. 릴리스 노트의 SHA-256 값으로 받은 파일을 확인할 수 있습니다.

## 소스에서 실행·빌드

Node.js 22.12 이상과 Windows 가 필요합니다.

```bash
npm install
npm start          # 개발 모드로 실행
npm run dist       # dist/Longroll-Setup-<버전>.exe 설치 프로그램 빌드
```

## 테스트

```bash
npm test                          # 전체 e2e 테스트
node test/run-e2e.js "<정규식>"    # TC id 가 정규식에 맞는 항목만 실행 (예: "^DSP-02")
```

- Playwright 로 Electron 앱을 구동하는 e2e 테스트입니다. 픽스처 이미지는 Python 3 과 [Pillow](https://python-pillow.github.io/)(AVIF 지원 필요)로 임시 폴더에 생성하므로 둘 다 설치되어 있어야 합니다.
- 테스트 창은 보조 모니터에만 띄웁니다. 보조 모니터가 `(-2560, 0)` 위치의 2560×1440 이라는 전제가 `test/run-e2e.js` 에 하드코딩되어 있습니다(창 시작 위치 `-2460,100`). 모니터 구성이 다르면 안전장치가 작동해 실행이 중단되므로 이 값을 환경에 맞게 수정해야 합니다.
- 앱은 환경변수 `LONGROLL_WINDOW_POS`(`x,y`)로 시작 위치를, `LONGROLL_USER_DATA` 로 사용자 데이터 경로를 바꿀 수 있으며 테스트가 이를 사용합니다.
